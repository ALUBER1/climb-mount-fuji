
# CLIMB **MOUNT** FUJI

###### A brief description of the game.

> _Climb mount Fuji_  is a 2D platforming adventure where the player takes on the role of a poor boy stuck inside a pot. His only chance to escape is to reach the top of Mount Fuji.
